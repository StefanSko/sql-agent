Why this shape

Each choice answers a concrete pressure observed during the probe—not a hypothetical platform requirement.

D-01

In-process MCP

PressureProbe MCP ergonomics without adding deployment and transport failure modes.
ChoiceWrap FastMCP directly with MCPToolset.
ConsequenceTool contracts remain portable; local deployment stays one process. source ↗
D-02

Schema exposure is policy

PressureSchema discovery costs model turns and tokens.
ChoiceMake three exposure modes interchangeable at one seam.
ConsequencePrefetched wins the bounded matrix while held-out schemas still pass. source ↗
D-03

Types carry states

Pressure“Success + truncated + error” cannot safely hide in booleans or anonymous JSON.
ChoiceFrozen dataclasses and QueryOk | QueryTruncated | QueryRejected.
ConsequenceEvery interface names its possible state. source ↗
D-04

Safety is layered

PressureA read-only transaction alone does not constrain privileged server functions.
ChoiceSingle-statement parsing, DML/DDL scanning, capability denylist, DB read-only mode, timeout, row cap, least-privilege role.
ConsequenceMissteps become typed rejections before data crosses the tool boundary. source ↗
D-05

AG-UI over bespoke SSE

PressureStreaming tool and text events by hand expands protocol ownership.
ChoiceDelegate event adaptation to AGUIAdapter; keep a frozen raw-SSE control.
ConsequenceRicher event semantics and less orchestration code, with a more capable browser client. source ↗
D-06

History remains optional

PressureFull resend grows, but lossy compaction can cost more tokens or semantics.
ChoiceAttach immutable ProcessHistory only through an explicit policy.
ConsequenceDefault remains simple; the hook is ready when evidence justifies it. source ↗

What crosses
the model boundary?

The architecture is easiest to reason about by naming both sides of the line.

Model-visible

  • Schema tool declarations or prefetched typed catalog
  • Natural-language request and request correlation ID
  • QueryResult rows, truncation, or sanitized rejection
  • Message history selected by the history policy

Application-only

  • Database DSN and Ollama API secret
  • asyncpg connection and transaction
  • PostgreSQL exception details
  • Experiment call traces; disabled for long-lived app routes
