Two entry paths,
one core

Interactive serving and reproducible experiments intentionally converge at the same agent, exposure, MCP, and database boundaries.

interactive route

Browser → AGUIAdapter

  1. Browser owns canonical AG-UI history.
  2. create_app disables long-lived result tracing.
  3. Framework adapter streams lifecycle events.
  4. Structured answer is bridged only if not already visible.
measurement route

Workload → run_agent

  1. WorkloadCase supplies prompt and typed scalar oracle.
  2. run_agent enables measured event and call tracing.
  3. AgentRun captures output + operational metrics.
  4. RunSucceeded | RunFailed enters deterministic ranking.
