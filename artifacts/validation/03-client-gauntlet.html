Decision rule
Restore AG-UIif at least two independent clients use its standard lifecycle/replay semantics and save ≥30% integration time or avoid bespoke state defects versus minimal SSE.
Restore / retain MCPif a second out-of-process consumer reaches parity without sharing Python code and the isolation/interoperability benefit exceeds transport operations.
Keep simplificationif “standard” integrations still require app-specific adapters while direct/minimal clients ship faster with the same required behavior.
Creative falsifier: offer a small bounty to any internal team that can demonstrate a useful unplanned client in one day using only MCP or AG-UI docs. A claimed standards layer with no takers has low option value; a surprise integration is powerful contrary evidence.
